# BRAIN

BRAIN — Be Right And Implement Next.

Be right: establish and retain what is currently right. Implement next: use that understanding to implement what comes next.

## Worked Evidence

This meaning was nearly lost. It was not durable in BRAIN, so it remained only in the Human's memory until the Human re-established it. Understanding that is not made durable can be lost; this node is BRAIN retaining it.
