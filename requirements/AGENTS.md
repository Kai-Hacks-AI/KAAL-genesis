# Requirements

Use BRAIN for why KAAL keeps Requirements here and what each records: `brain/learning/genesis/26/09/28/01/nodes/managing-requirements.md`.

Use the `managing-requirements` skill to record and check them, through `npm run requirements:record` and `npm run requirements:check`. A Requirement states what KAAL commits to hold, not how it is proven: it names no case and no state, and a case that helps prove it points at it with `// Why: requirements/<name>/requirement.md`. Its record is never written again.
