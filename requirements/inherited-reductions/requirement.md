---
holds: KAAL names every part of what the accepted Regression Plan requires that
  a candidate's no longer does, from both states' own files, and nothing else
---

Given two states of KAAL's files, an accepted state and a candidate proposed to succeed it, KAAL names every reduction the candidate would make of what the accepted regression protects. What the accepted regression protects is what the accepted state's Regression Plan requires, read as KAAL reads any plan's requirements: each commitment it names, each suite that serves it and each proof other than cases it requires, each under every set of conditions it is required under; each check other than cases the plan says shows a commitment; and each file a place it names by a wildcard covers. A reduction is any of those the candidate's Regression Plan no longer requires: a requirement it no longer requires at all, or no longer under a set of conditions, a check it no longer says shows a commitment it keeps, or a file a wildcard it keeps no longer covers. A set of conditions is still required where the candidate requires a set every run meeting which meets it too. A requirement lost is one reduction, and so is a set of conditions nothing is required under any more. KAAL reads only the two states' own files, as directories, and asks neither Git nor GitHub which is which; what the links check refuses of either state, such as a place outside it or a plan or suite reached through a link, is refused, never read.

Nothing else is a reduction. What the candidate adds, and how it changes its code, its cases or their arrangement, reduces nothing its Regression Plan still requires: cases are evidence for what is required, not what is required.

A Requirement the accepted Regression Plan names that the candidate removes or rewrites, whether or not it still names it, is a loss that cannot be accepted: a Requirement never changes, and an accepted loss lets its commitment leave the regression, never its record.

Where this ends: which cases show a requirement, and how much of it, is not read here, so a case the candidate no longer keeps is not named as a reduction.
