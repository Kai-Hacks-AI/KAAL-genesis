holds: The evidence a regression projects is the accepted evidence itself, held
  as it was admitted and replayed against every later candidate, whatever the
  candidate does with its own testing; a candidate's own evidence enters beside
  it only where something other than the candidate's own output judges it, and
  only an acceptance record gives any of it up
---

Feature adds, Acceptance removes, Regression projects. What the next regression protects is what the accepted regression protects, less what the candidate explicitly gives up, with what it newly promises and demonstrates. The evidence that demonstrates it is projected: the accepted regression's own evidence, carried into the next regression as it is, never a candidate's own testing taken to prove the same.

A regression holds the evidence it projects apart from the testing a candidate carries, under `change/<name>/test/`, each change's evidence as that change brought it in: its case files and the test data they were admitted with, at the paths they were kept at, byte for byte, with a record of the cases held there that are no longer projected. The evidence a regression had before it held any, its own testing, is held as `genesis`. The same case at the same path, held by two changes, is two pieces of evidence, each replayed on its own, from where it is held.

Every case the accepted regression projects and no acceptance record gives up is replayed against the candidate, and carried into the next regression as it is held. The candidate's own testing may carry it unchanged, rewrite it, move it or drop it; none of that replaces or removes it. An acceptance record giving up a case of a file whose others it keeps leaves the file held as it was, with that case no longer projected; once every case a held file projects is given up, the file is no longer held, and once a change holds none, neither is its evidence.

A candidate's own evidence enters beside what is projected, admitted to the change the candidate belongs to, where no evidence carried already holds the same bytes at its path. A case of it is projected only where something other than the candidate's own output judges it: it demonstrates a promise the candidate newly makes, it tests a defect the candidate records, or it holds against the accepted code. Any other case of it is held but not projected. A change never holds two pieces of evidence at one path, nor test data other than the candidate's; evidence it cannot hold there is not admitted. A new promise enters with the evidence that demonstrates it, or not at all.

A candidate holds exactly the evidence the next regression projects, as derived from the accepted regression and the candidate's files, byte for byte, and admits its own to one change only. Before any regression held evidence, each projected its own testing, and a candidate of one holding none was judged by the cases it carried; once either holds evidence, the projection judges it, and no later regression returns to its own testing.

Where this ends: it does not decide what is protected, which is what the candidate gives up and newly promises; it gives nothing up, which only an acceptance record does; it never decides that a candidate's evidence proves the same as the accepted evidence, which it keeps instead. What a replay composes is the held testing state with the candidate as the tested state, by the replay's existing boundary: a helper a held case imports from outside its test data is taken from the candidate, what a case reads of the state it runs in, beyond its subject, is not held, and what else takes part in a run is not recorded. Those belong to completing what a run records. It does not accept, seal or release the regression it projects.
