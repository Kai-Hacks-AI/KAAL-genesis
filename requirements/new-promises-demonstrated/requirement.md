---
holds: what a candidate newly promises is demonstrated only when the candidate's
  own cases show each new promise held under every set of conditions required
---

Each commitment a candidate newly promises relative to the accepted state is required of the candidate's own testing, beside whatever else KAAL's Feature testing requires: it is shown by the candidate's cases that say they help prove it, run against the candidate, under every set of conditions that testing states, which are those the Regression Plan states for KAAL's commitments.

A new promise is demonstrated only as any requirement of a plan is: it held under a set of conditions only when a run under them reached a case that helps prove it and every case it reached passed. A new promise no case of the candidate proves is not demonstrated, however every other case fares; one whose case failed has failed. What the candidate newly promises is demonstrated only when every new promise, and everything else required, held under every set.

A candidate that newly promises nothing adds nothing to what is required: nothing is owed for it, and nothing is demonstrated by it.

Where this ends: showing a new promise demonstrated says nothing about any commitment the accepted state already states, which stays for the accepted regression's checks to show, and decides nothing about any the candidate stops stating.
