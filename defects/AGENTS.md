# Defects

Use BRAIN for why KAAL keeps defects here and what each records: `brain/learning/genesis/26/09/27/02/nodes/managing-defects.md`.

Use the `managing-defects` skill to record and check them, through `npm run defects:record` and `npm run defects:check`. A defect's record never changes once written, and nothing beside it records its state.
