# KAAL catalogue

The Skills and Extensions this KAAL distribution makes available to install, one per line as `- <kind> <name>`. Core reads this file and nothing else to know what is available: it does not scan directories and knows nothing of what a Skill or Extension is. Being listed here installs nothing and registers nothing.
