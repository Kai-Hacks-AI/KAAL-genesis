id: the-using-system-judges-which-candidate-its-evidence-concerns
---

Testing keeps what each Run states of its candidate and does not judge it; which candidate a using system's evidence must concern is the using system's to say and to check.

Evidence is shown by several Runs that require the same instances and differ in the conditions they ran under. Runs that agree with one another on a candidate identity would not thereby concern the candidate the using system requires, which only it knows, so no comparison among the Runs alone can settle it: it is a comparison of what each Run states against the identity the using system requires, and it belongs to the using system's composition. Testing retains, serializes, deserializes and exposes the identity a Run states, and never compares, interprets or comments on it, its evidence command included. This confirms the earlier decision that the using system ensures that Runs judged the same candidate, and changes what it ensures it with: a durable fact in each report instead of a provider-side side channel. A Testing option that demands an identity is not earned until compositions repeat that check.
