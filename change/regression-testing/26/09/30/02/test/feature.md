# Feature

This Change lets a Suite name its Cases where they already live, and it brings the protection KAAL already had under Regression Testing. The only protection it introduces is the testing skill's own tests, which the first Regression Test Plan did not name. The Suites collecting existing protection are new, but the protection is not: it is Genesis's, Change's, the seal guard's and Reviewing's, reconstructed in `reconstructed/`.
