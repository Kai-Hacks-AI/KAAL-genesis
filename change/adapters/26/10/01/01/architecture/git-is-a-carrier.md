---
id: git-is-a-carrier
---

Git is a carrier, and what is specific to Git belongs to a Git adapter.

That is repository and history mechanics: reconstructing a state at a commit, diffing against a base, merge bases, objects, trees, refs and the staged index, and the autocrlf checkout behaviour that changes the bytes of a file. A Git fact is Git's even where a host also displays it. KAAL's Change, Requirement, Defect, Test Case, Plan, Run, Review, Seal and BRAIN do not take their meaning from a commit, a branch or a Git history.
