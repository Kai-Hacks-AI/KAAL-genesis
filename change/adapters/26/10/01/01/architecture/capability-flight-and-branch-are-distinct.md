id: capability-flight-and-branch-are-distinct
---

A capability, a flight and a branch are three different things, and none of them is derived from another.

A capability owns its meaning. A flight is concurrent work toward an evolution. A branch is how a carrier and a host realize that concurrent work, and its name is the realization's name, not an owner of anything. The Git and GitHub adapters own what a branch is and which names a host admits, so the name of a branch, or the branch earlier pull requests happened to target, never says which capability owns a semantics: ownership is stated meaning, and is found where it is stated.
