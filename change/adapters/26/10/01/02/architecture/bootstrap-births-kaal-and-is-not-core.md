---
id: bootstrap-births-kaal-and-is-not-core
---

Bootstrapping is the operation that births or installs KAAL, and it is not installed Core.

An operation such as kaal init births KAAL: it installs Core, Skills, Extensions and BRAIN. Installed Core is machinery that stays in KAAL after that operation has run; the operation is not a placement within it, and the two are not conflated because one piece of code happens to do both kinds of work. Genesis is today's scaffolding for evolving this repository: it composes Skills to birth BRAIN and an Agent entry point, it is evidence for the eventual operation, and it is not the definition of the installed Core and need not survive a clean birth.
